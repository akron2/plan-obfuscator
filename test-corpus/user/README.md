# User corpus

Сюда добавляются только синтетические или заранее обезличенные `.sql`, `.txt`,
`.log` и `.out` файлы. Все они автоматически участвуют в corpus tests.

Идентификаторы и значения, содержащие `PRIVATE` или `SECRET`, автоматически
проверяются как обязательные для замены. Если нужны дополнительные ожидания,
они добавляются в необязательный `expectations.json` этого каталога по общей
схеме `../corpus.schema.json`. Файл без `PRIVATE`/`SECRET` должен быть явно
добавлен в expectations, иначе corpus test намеренно завершится ошибкой.
